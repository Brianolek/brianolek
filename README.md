# brianolek — the artist site

Static site for Brian Olek, oil painter. No build step.

- `index.html`, `css/style.css`, `js/main.js`, `js/smear.js` (WebGL hero)
- `works.json` is the catalogue. Edit titles, sizes, years, notes there. `hero: true` picks the hero painting.
- `img/full` (1800px) and `img/thumb` (640px) are generated by `python3 tools/process_images.py`
  from `~/Desktop/Painting/Warbuck PNG`. Add a work by adding a row to works.json with its `src`, then rerun.

Run locally: `python3 -m http.server 3324` in this folder, open http://localhost:3324.
Deploy: GitHub Pages from repo Brianolek/brianolek, branch main. `git push` publishes. Domain: brianolek.com (CNAME file).
